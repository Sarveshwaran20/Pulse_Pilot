## ⚡ TOP 5 "MUST-KNOW" QUESTIONS (HIGHEST PROBABILITY)

---

### 1. "How do you guarantee that health data never leaves the user's computer?" (Security & Privacy)
- **15-Second Answer:**
  > "We enforce an absolute architectural air-gap: our Python FastAPI vault binds strictly to `127.0.0.1` on localhost with zero external egress and local SQLCipher AES-256 encryption. Furthermore, the MCP server only exposes a coarse deterministic state string (`COGNITIVE_FATIGUE`) to agents—never raw heart rate or sleep numbers. You cannot leak data that is never transmitted."

---

### 2. "Consumer wearables have noisy PPG sensors. How do you prevent false-positive fatigue triggers?" (Biomedical)
- **15-Second Answer:**
  > "We don’t rely on instantaneous heart rate. PulsePilot computes a rolling 7-day median baseline filtered through a bandpass filter (0.5 to 4.0 Hz) and only samples resting heart rate during stage-3 non-REM slow-wave sleep when motion artifacts are zero. A fatigue state requires a compound convergence: elevated RHR, high sleep debt, and prolonged screen time simultaneously."

---

### 3. "Why use Anthropic's Model Context Protocol (MCP) instead of standard API function calling?" (AI Architecture)
- **15-Second Answer:**
  > "Function calling locks tools inside a single vendor’s API. MCP is the open JSON-RPC standard supported across Claude, Gemini, Antigravity, and Cursor. By implementing MCP at the sidecar transport layer, PulsePilot intercepts tool calls universally without touching LLM prompts or re-writing wrappers."

---

### 4. "If an agent is hijacked by prompt injection or hallucinates, does PulsePilot stop it?" (AI Safety)
- **15-Second Answer:**
  > "Yes, 100%. Traditional guardrails live inside the LLM prompt, so they can be jailbroken. In PulsePilot, execution authority lives strictly outside the LLM. The MCP server intercepts all mutating tool calls (`SideEffect: True`) at the OS process boundary and refuses to execute without a physical cryptographic token generated by an intentional human click."

---

### 5. "What prevents Apple or Google from building this directly into iOS or macOS tomorrow?" (Defensibility & Moat)
- **15-Second Answer:**
  > "Ecosystem silos. Apple will never build an MCP server that gates an open-source Ollama model running on Linux, and Google won't prioritize an Apple Watch controlling Claude Desktop. Furthermore, enterprise defense and fintech clients refuse to let employee biometrics touch big tech clouds. PulsePilot is the neutral, open-core, zero-egress hardware-to-agent bridge."

- **15-Second Answer:**
  > "Based on Kahneman's dual-process theory, instant clicking is an automated System 1 motor reflex. Neurobiology shows that prefrontal cortical veto power activates within 400 to 800 milliseconds. A 1,500ms physical hold breaks the motor loop and forces System 2 cognitive deliberation."

- **15-Second Answer:**
  > "We use zero hardcoded static thresholds. Everything is evaluated as a personalized Z-score against that specific individual’s rolling 7-day and 30-day baseline stored locally. A 58 bpm reading is flagged as an anomaly for an athlete, but completely normal for an average adult."

### 9. "What if the user isn't wearing a smartwatch or health tracker?" (Graceful Degradation)

### 10. "How much latency does your MCP gating server add to an agent's workflow?" (Performance)
- **15-Second Answer:**
  > "Less than 1.8 milliseconds. Because the server runs locally over loopback I/O with in-memory SQLite state caching, there is zero WAN roundtrip overhead. Read tools execute instantly, and mutation checks evaluate in microseconds."

### 11. "Can a malicious website or script bypass your browser extension?" (Web Security)
- **15-Second Answer:**

- **15-Second Answer:**

## 📋 3 RULES FOR THE 2-MINUTE Q&A SESSION

1. **Stop at the 18-second mark**: Deliver the punchline, cite the technical stat, and close your mouth. Let the panel lead the conversation.
2. **Never defend defensively**: If a judge points out a limitation, acknowledge it as an engineering trade-off: *"That is an intentional architectural boundary to preserve zero-egress HIPAA compliance on localhost."*
3. **If a judge interrupts you**: **Stop speaking immediately and listen.** An interruption means they got your point and want to dive deeper—interrupting an interrupted judge loses marks.
